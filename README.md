# João Victor Beato

I take CRM and martech projects from the architecture to production: I design the data model, integrations and automation, and lead the squad that builds them through hypercare. I work across Salesforce (Sales, Service, Marketing Cloud, Data Cloud, Loyalty, Agentforce), Braze and Insider One, for clients in retail, capital markets, fintech, wealthtech, sports and education.

Among the architectures I designed is Hirota Food's loyalty program, in production since November 2026, with the case published on [Salesforce Brazil's blog](https://www.salesforce.com/br/blog/transformacao-digital-hirota/).

## How I deliver

The repository is the source of truth, and every change made in an org goes back to version control in the same delivery. Code Analyzer runs on every pull request, and the scan before each delivery adds the Graph Engine security rules. Apex tests run as the profile user who will use the feature, production deployments are validated in production before the release window, and architecture decisions are recorded as ADRs. AI agents speed up documentation, QA and code review, always under technical review. Some of the tools I deliver with are open source and pinned below.
